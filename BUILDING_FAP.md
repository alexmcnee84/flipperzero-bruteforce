# Building a `.fap` package

The Python generator in this repository only produces `.sub` files. If you would like to ship the
material as an installable Flipper application you can wrap the data inside a minimal external app
and compile it with the official Flipper build system. The steps below use the [ufbt](https://github.com/flipperdevices/flipperzero-ufbt)
tool because it is lighter than checking out the whole firmware tree manually.

> **Note**
> The provided template does not try to play the Sub-GHz files directly. Instead it shows a helper
> dialog on the device explaining where to copy the generated `.sub` files. You can replace the
> template with a richer application if you want to automate transmissions.

## 1. Install ufbt

```bash
pipx install ufbt
```

See the ufbt documentation if you prefer another installation method.

## 2. Create a workspace

```bash
mkdir ~/flipper-workspace
cd ~/flipper-workspace
ufbt clone
```

This downloads the firmware skeleton that the build system requires.

## 3. Copy the template app

Inside this repository you will find a small application skeleton in `fap_template/`. Copy its
content inside the workspace that ufbt created:

```bash
cp -r /path/to/flipperzero-bruteforce/fap_template/applications_user \
      ~/flipper-workspace/
```

After the copy you should have an `applications_user/bruteforce_bruteforce` directory inside the
workspace containing `application.fam` and `bruteforce_bruteforce.c`.

## 4. Generate the Sub-GHz data

Back in this repository run the generator so that you have fresh `.sub` files:

```bash
cd /path/to/flipperzero-bruteforce
python3 flipperzero-bruteforce.py
```

Copy the resulting folders (everything under `sub_files/`) to the SD card image that you normally
synchronise with your Flipper. The FAP produced in the next step merely tells the user where the
files live, so you are free to organise them as you prefer (for example `SD:/subghz/bruteforce/`).

## 5. Compile the `.fap`

Launch the build inside the ufbt workspace:

```bash
cd ~/flipper-workspace
ufbt fap bruteforce_bruteforce
```

The command outputs something similar to:

```
Build cache: build/f7-fap
FAP: build/f7-fap/bruteforce_bruteforce/bruteforce_bruteforce.fap
```

Copy the produced `.fap` file to your Flipper (`SD:/apps/`). When launched, the helper app displays
instructions reminding you where the brute force `.sub` files are stored.

## 6. Customising the helper app

The helper template is intentionally simple. If you want to provide an automated bruteforcing
experience you can modify the code in
`fap_template/applications_user/bruteforce_bruteforce/bruteforce_bruteforce.c` to iterate over the
files generated by the Python script and transmit them programmatically. The ufbt tool takes care of
recompiling the application whenever the C sources change.
